This folder contains a set of preprocessed (simplified) SVG files,
so that you can import the SVG-path and its color without no need to parse the SVG files.

Each file contains a list of layers;
  each layer is made of 2 elements:
    a color  (e.g.  #664412 )
    a (very long) d-path (e.g. "M0.834-0.085v ....... " )

layers are listed from bottom to top.
